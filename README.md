# MININT Prova

Aplicativo de estudo para a preparação da prova, desenvolvido pela **2-ON Soluções**.

## Descarregar

[Descarregar a última versão (APK para Android)](https://github.com/2On-Solucoes/minint-prova-download/releases/latest/download/MININT-Prova-Escrita.apk)

## Como instalar

1. Descarregue o ficheiro `MININT-Prova-Escrita.apk` no seu telemóvel Android.
2. Abra o ficheiro. Se o telemóvel pedir, permita instalar de fontes desconhecidas.
3. Abra o aplicativo, leia e aceite os termos de utilização.

O aplicativo inclui um período de teste grátis. Depois, o Plano Premium (pagamento único) liberta o uso sem limite de tempo.

## Aviso

Este aplicativo foi desenvolvido apenas para fins preparatórios, com as matérias disponíveis e aconselhadas pelo site oficial do MININT. O site oficial do MININT é o único que devemos seguir e é nele que se confirmam as candidaturas. O MININT Prova **não pertence ao Ministério do Interior**.
